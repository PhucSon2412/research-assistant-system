# A Survey of Efficient Routing in Multilingual Translation

Authors: Irene Castell and Dev Malhotra (fictional authors; synthetic evaluation paper).
Identifier: doi:10.5555/ras-eval.p06 (fictional, not registered).

## Abstract

This survey covers 41 papers on efficient routing for multilingual translation published between 2019 and 2026.

## Sparse Routing

Sparse routing methods such as Gated Sparse Routing were reported to improve Kinyarwanda–English BLEU by 2.4 points [1], although a later replication found a smaller gain [2].
Adapter-based methods trade smaller gains for far lower training cost [3].

## Recommendations

We recommend reporting tokenizer settings for every baseline, because tokenization differences can change BLEU by more than one point.
Surveys of routing methods should also report the number of random seeds.
