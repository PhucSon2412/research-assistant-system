## Hợp đồng và transaction

**Review độc lập PR #38 tại `97c49d8`: 182/182 test chọn pass**, gồm C2d-1 93, login/session 68, invitation/outbox 20 và ORM/schema 1; 0 failure/error/skip. Không cộng với số 490 và đối chứng của agent bên dưới hoặc coi là full inventory/cutover.

[`identity/final_caller.py`](../api/app/identity/final_caller.py) nhận đúng session ID/User ID đã xác thực; bỏ qua role/email cũ. Gọi `auth_safety.require_final` trên transaction hiện hành để giữ journal shared; lấy scalar columns allowlist (không ORM identity map/verifier/digest/token), kiểm `session_live(..., user_id=...)` bằng clock sau lock wait/profile query, rồi **lấy clock nữa sau SQL predicate**, kiểm lại idle/absolute và gán checked_at. Predicate SQL `0035` buộc latest confirmed credential/status head, receipt đủ binding, session generation và idle/absolute expiry. Không mở held/quarantine/legacy; helper không touch, issue, commit, rollback hoặc lấy User/session row lock.

Session không live/sai owner → `401 session_expired` + clear cookie; live nhưng role hiện tại không Admin → `403 forbidden`; integrity/hold/pending/lock lỗi → `503 service_recovering`. DTO chỉ profile, session ID/expiry và thời điểm kiểm. `idle_expires_at = min(last_activity_at + idle, absolute_expires_at)` giữ semantics của SessionContext cũ, kể cả hoạt động gần cuối absolute lifetime. Không cache proof qua commit; không thay entry dependency/Origin/CSRF hoặc SQL ACL. Writer cần exclusive journal không được dùng helper này để nâng shared → exclusive hoặc lấy User sau resource/journal.

| Route | Thứ tự quyết định cuối |
| --- | --- |
| `auth.current_session` | Dependency resolve/touch/commit/check/rollback → helper trên transaction route → profile/role/expiry mới → response; transaction đóng bởi dependency DB |
| `admin.list_users` | Query toàn account, dựng DTO allowlist → helper current Admin → response; account held/legacy của target vẫn có trong danh sách |
| `admin.dev_outbox` | Development + DevOutbox → audit ID/mã + flush FK → helper Admin → commit audit xác định → helper **transaction mới** trước entries → snapshot bộ nhớ có giới hạn → helper/clock sau snapshot → bỏ entries đã hết TTL → response |

DevOutbox dùng `commit_activity` hiện có cho commit không auth event: mọi exception, kể cả commit thật đã landed nhưng mất reply, trả controlled `503 auth_outcome_uncertain`, không messages. Flush lỗi trả `503 auth_unavailable`. Audit không chứa recipient/link/token; audit đã commit có thể tồn tại dù hậu kiểm từ chối. Helper không chạy adapter/send. Snapshot chỉ đọc bộ nhớ bounded bởi config; không storage/provider/delivery I/O khi giữ journal. TTL dùng thời điểm sau snapshot, không `get_now` đầu request.

Final journal shared bảo vệ writer tuân thủ journal protocol tới commit/rollback của transaction. Thay đổi đã thắng trước final phải chặn payload. DTO/response đã qua final boundary và nhả khóa có thể tiếp tục gửi; bytes đã gửi không thu hồi. Không hứa hủy hồi tố response hoặc chống DBA sửa SQL ngoài trust boundary. Ca race kiểm writer đợi shared lock, reader nhả rồi writer hoàn tất, proof mới bị từ chối trong khi DTO cũ vẫn tồn tại.
